# FUDOPIA - World Food Hub

FUDOPIA is a static web project showcasing iconic dishes from around the world.
It includes country filters, food cards, fun facts, and a local browser-based adventurer counter.

## Features

- Interactive world food gallery
- Country filter buttons
- Random cultural food facts
- Mobile-friendly static site layout
- Local storage adventurer count

## Files

- `index.html` — main page structure
- `styles.css` — presentation and responsive layout
- `script.js` — UI rendering, filtering, and section navigation
- `data.js` — food dataset and fun facts
- `logo.png`, `jcr.png` — image assets
